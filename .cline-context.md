## PROJECT OVERVIEW

**Wokman** is a polished Chinese takeaway ordering website for **Fortune House**, a UK-based Chinese takeaway. It's a Vite + React + TypeScript + Tailwind + shadcn/ui stack, deployed on **Vercel**.

- **Repo:** `https://github.com/stmak/wokman` (also cloned at `/Users/sengmak/Desktop/wokman`)
- **Author:** stmak
- **Stack:** React 18, Vite 5, Tailwind 3, shadcn/ui (Radix UI), React Router 6, TanStack Query 5
- **Runtime:** Bun (locks: `bun.lock`, `bun.lockb`)
- **Deployment:** Vercel serverless functions (`api/verify-vip.ts`)
- **Port:** 8080 (configured in vite.config.ts)

## ARCHITECTURE & STATE MANAGEMENT

### VIP Gate System
- The site is **locked** by default. "Add to cart" buttons are disabled until a VIP code is entered.
- VIP codes validate via a serverless API: `POST /api/verify-vip` validates against `process.env.VIP_CODE` on Vercel.
- The `unlocked` state persists in `localStorage` under key `golden-wok-takeaway-state`.

### Cart System
- Cart stored as `CartItem[]` in `TakeawayContext` (React Context).
- Persisted to localStorage on every change.
- **Sanitization:** On load, `sanitizeCart()` validates every cart entry against `validDishIds` (all menu + bundle IDs), caps quantities, and limits lines to `MAX_CART_LINES` (50). Tampered/corrupt data is discarded.
